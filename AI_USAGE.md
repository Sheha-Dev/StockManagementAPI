# AI Usage Notes — Backend API

## AI Tool Used

I used ChatGPT as a development assistant while implementing the ASP.NET Core Web API.

## Areas Where AI Assisted

### 1. API File Structure and Boilerplate

I used AI to help generate the initial API-related file formats and boilerplate code, providing a starting point for organizing the backend implementation.

### 2. Application DbContext

I used AI to generate the initial `AppDbContext` structure for Entity Framework Core and help organize the database context and entity configurations.

### 3. Custom Exception Handler

I used AI to generate an initial custom exception-handling implementation to centralize exception handling and provide consistent error responses.

## Verification and Limitations

AI-generated code was treated as a starting point. I reviewed and adapted the generated code to fit the application structure and assessment requirements.





## My Own Contributions and Decisions

I was responsible for understanding the assessment requirements, reviewing the generated code, making implementation decisions, and adapting the solution to the stock-transfer workflow.

My focus was on the business rules governing transfer statuses, stock availability, valid quantities, and preventing repeated operations from moving stock more than once.

I am responsible for understanding and explaining the final implementation, including any AI-assisted code.
